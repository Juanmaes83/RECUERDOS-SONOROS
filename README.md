# RECUERDOS SONOROS

**Capture the soundtrack of your life.**

Recuerdos Sonoros is a product concept for capturing and reconstructing meaningful moments by linking what the user saw, heard, where they were, who they were with and what they felt.

The core product is not a photo gallery with music. It is a **multimodal personal memory system**.

## Product thesis

A photograph remembers what a moment looked like. Music can bring back what that moment felt like.

Recuerdos Sonoros combines both with contextual signals such as time, location, place, people, notes and other metadata to create a richer `Memory Object` that can later be searched, connected and relived.

## Core loop

`CAPTURE → RECOGNISE → ENRICH → STORE → RELIVE`

Initial capture target:

- Photo or short video
- Song identity and approximate song timestamp
- Date and time
- GPS coordinates and recognised place
- Optional written or voice note
- Optional people / activity / emotion / event context

Future layers:

- Audio-reactive photographs and visual memories
- Sound memory map
- Memory graph across songs, people, places and periods
- Automatic trip / summer / year films
- Personal life soundtrack
- AI-assisted memory retrieval and reconstruction
